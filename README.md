# Watavyu

Fork of Datavyu aimed at modernization and simplification.

## Citing

If you use Watavyu in your research, please cite it. The citation lives in [CITATION.cff](CITATION.cff): GitHub's "Cite this repository" button and the app's Help > Cite Watavyu (APA and BibTeX, with the running version and Copy buttons) both read it.
