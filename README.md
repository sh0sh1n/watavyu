# Watavyu

Fork of Datavyu aimed at modernization and simplification. Projects are saved as readable JSON files (`.watavyu.json`); see [BUILDING.md › Project Files](BUILDING.md#project-files). [BUILDING.md](BUILDING.md) covers building, testing and playback; [TODO.md](TODO.md) tracks known bugs and planned work; [AGENTS.md](AGENTS.md) records the direction and the decisions behind it.

## Installing

Watavyu runs on Apple Silicon Macs with macOS 27 or later. No release has been published yet; releases will be disk images, signed by sh0sh1n LLC and notarized by Apple: open one and drag Watavyu to Applications. Java comes inside the app. [BUILDING.md › Distribution](BUILDING.md#distribution) covers how a release is made.

## Citing

If you use Watavyu in your research, please cite it. The citation lives in [CITATION.cff](CITATION.cff): GitHub's "Cite this repository" button and the app's Help > Cite Watavyu (APA and BibTeX, with the running version and Copy buttons) both read it.
